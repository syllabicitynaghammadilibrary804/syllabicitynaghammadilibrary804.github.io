Download nativ for Windows

nativ brings the power of local AI to your desktop. You can chat with models, track their performance, and connect your own data without worrying about cloud privacy or complex server setups. We built this app so you can harness machine learning technology directly on your hardware.

🚀 Getting Started

You do not need to be a developer to use this software. This guide helps you set up the app on your Windows computer in minutes. Ensure your computer meets the minimum requirements below before you begin the process.

📂 System Requirements

  • Windows 10 or Windows 11.
  • At least 8GB of RAM.
  • A modern processor (Intel Core i5 or AMD Ryzen 5 or better).
  • 5GB of free storage space for model downloads.

💾 Installation

Follow these steps to install nativ on your machine:

  1. Visit the download page: Go to this link to access the latest installer.
  2. Save the file: Select the Windows installer file and save it to your Downloads folder.
  3. Run the installer: Double-click the file to start the installation. If Windows asks for permission to run the app, click "Run" or "Yes."
  4. Follow instructions: The on-screen wizard guides you through the process. Click "Next" until the setup completes.
  5. Launch the app: Find the nativ icon on your desktop or in your Start menu and open it.

⚙️ How to use nativ

Once you open the software, you see a clean dashboard. Follow these steps to start your first chat:

  • Select a Model: From the model menu, pick a model that fits your needs. If the list is empty, click "Refresh" to fetch available models.
  • Start a Chat: Type your question in the text box at the bottom of the screen and press Enter.
  • Monitor Resources: Check the status bar at the top of the app to see how much memory the model uses while it runs.
  • Change Settings: Use the settings menu to adjust how the model behaves and to manage your downloaded files.

🛡️ Privacy and Safety

Your data stays on your computer. When you use nativ, no information goes to a central server. Everything happens locally, which keeps your documents and chats private. We include tools that allow you to wipe your chat history and model cache whenever you choose.

💡 Troubleshooting

If you encounter issues during setup or usage, consider these common fixes:

  • App does not open: Restart your computer and try launching it again.
  • Slow performance: Close other intensive programs, like web browsers or video games, while using nativ.
  • Download errors: Check your internet connection if the app fails to fetch a model.
